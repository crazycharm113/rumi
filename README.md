# 블로그 작업대 (패션 블로거 작업 도우미) — 1단계

기획서 v2의 개발 순서 중 **1단계(주제 정하기)** 를 구현한 프로그램입니다.
본인만 쓰는 도구라 로그인 없이 내 컴퓨터에서만 열립니다.

| 화면 | 하는 일 |
|---|---|
| 오늘의 브리핑 | 날씨 바(오늘 기온, 어제·내일 차이, 맞는 옷, 기온 급하강 예고) · 오늘 올릴 주제 3개와 이유 · 급상승 키워드(순위 변동) · 이번 주 발행 예정 |
| 키워드 기회 | 키워드별 14일 흐름, 7일 관심도 변화, 블로그 글 수, 기회 점수(계산식 공개) · 연령대 필터 · '요즘 많이 올라오는 아이템'(옷 종류·브랜드 언급 수) |
| 상품 보드 | 글 1개 = 보드 1개. 링크 붙여넣으면 상품명·브랜드·가격·썸네일 자동 채움 · 상태(후보/구매/촬영/발행) · 유형(직접 구매/협찬/제휴) · 사이즈·착용감·코디 메모 · 가격 기준일 |
| 설정 | 날씨 지역, 연령대, API 키, 지켜볼 키워드 |

2단계(브랜드 할인·신상, 가격·품절 알림, 콘텐츠 캘린더)와 3단계(포스팅 도우미, 성과 기록)는 기획서대로 1단계를 일주일 써 본 뒤 붙입니다.

## 실행

1. [Node.js](https://nodejs.org) LTS(18 이상)를 설치합니다. 따로 설치할 패키지는 없습니다.
2. 이 폴더에서 실행합니다.
   - Windows: `실행하기.bat` 더블클릭
   - Mac: `실행하기.command` 더블클릭 (처음엔 우클릭 → 열기)
   - 또는 터미널에서 `npm start`
3. 브라우저에서 http://localhost:3000 을 엽니다.

API 키 없이도 **예시 데이터**로 모든 화면을 둘러볼 수 있습니다(화면에 노란 안내가 뜹니다).

## API 키 (무료)

| 용도 | 발급처 | 넣을 곳 |
|---|---|---|
| 검색 관심도(연령대 포함), 블로그 글 수, 블로거 아이템 집계 | [네이버 개발자센터](https://developers.naver.com/apps/#/register) → 애플리케이션 등록 → 사용 API: **데이터랩(검색어트렌드)**, **검색** | 설정 → 네이버 API |
| 날씨 | [공공데이터포털](https://www.data.go.kr) → '기상청_단기예보 조회서비스' 활용 신청 | 설정 → 기상청 서비스 키 |

키는 이 컴퓨터의 `data/db.json`에만 저장됩니다. `.env` 파일(`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `KMA_SERVICE_KEY`)로 넣어도 됩니다.

## 계산 방식

- **관심도 변화**: 데이터랩 일별 지수의 최근 7일 평균 ÷ 그 전 7일 평균. 오늘은 집계 중이라 어제까지 씁니다.
- **관심 수준**: 데이터랩 값은 요청마다 상대값이라, 모든 요청에 '코디'를 기준 키워드로 함께 넣어 '코디 = 100' 기준으로 맞춥니다. 1 미만은 추천에서 뺍니다.
- **블로그 글 수**: 네이버 블로그 검색 결과 총 건수(근사치).
- **기회 점수** = 관심도 변화 지수 ÷ log10(글 수 + 10). 참고용입니다.
- **오늘 주제 3개**: 기회 점수 × 시즌 적합도(오늘 또는 며칠 안 기온이 그 아이템을 입는 기온 범위면 가산).
- 외부 데이터는 하루 한 번 저장해 재사용하고, 가져오기에 실패하면 마지막 데이터와 갱신 시각을 보여줍니다.

## 지켜야 할 것 (기획서 '리스크와 주의사항')

- 상품 정보는 **내가 저장한 링크만, 저장할 때 한 번** 읽습니다. 쇼핑몰 전체 수집은 하지 않습니다.
- 썸네일은 앱 안 참고용입니다. 글에 쓸 이미지는 직접 촬영하거나 브랜드 허용 범위를 확인하세요.
- 협찬·제휴 상품이 담긴 보드에는 광고 표시 안내가 뜹니다. 최신 기준은 직접 확인하세요.
- 블로그 비밀번호는 받지 않습니다.

## 파일 구조

```
server.js          서버와 API
lib/catalog.js     기본 키워드·기온별 옷차림·지역·연령 코드·브랜드 사전
lib/naver.js       네이버 데이터랩/검색 API
lib/weather.js     기상청 단기예보, 격자 변환
lib/analysis.js    기회 점수, 급상승, 주제 3개 고르기, 아이템 집계
lib/product.js     상품 링크 자동 채움
lib/service.js     화면용 데이터 모으기 + 하루 캐시
lib/store.js       data/db.json 저장
public/            화면(HTML/CSS/JS)
test/              npm test
```
