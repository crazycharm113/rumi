# 블로그 작업대 (패션 블로거 작업 도우미)

기획서 v2의 1~3단계 기능을 모두 담은 프로그램입니다. 본인만 쓰는 도구라 로그인 없이 내 컴퓨터에서만 열립니다.

| 화면 | 하는 일 | 단계 |
|---|---|---|
| 브리핑(홈) | 날씨 바 · 오늘 올릴 주제 3개(상품 보드 만들기 / 캘린더에 올리기) · 급상승 키워드 · 오늘의 할인·신상 · 내 상품 알림 · 이번 주 일정과 비어 있는 날 | 1·2 |
| 키워드 | 기회 점수 표(계산식 공개), 연령대 필터, 요즘 많이 올라오는 아이템·브랜드 | 1 |
| 할인·신상 | 관심 브랜드의 세일·신상 소식(최근 2주 블로그 글), 새 소식 표시, 캘린더에 세일 기간 넣기 | 2 |
| 상품 보드 | 글 1개 = 보드 1개. 링크로 상품 자동 채움, 상태·유형·사이즈·코디 메모, 글 상태(구상/촬영/작성/발행), 협찬 마감일 | 1·2 |
| 글쓰기 도우미 (보드 안) | 상품 정보 표 복사(네이버 에디터에 표로 붙여넣기), 제목·태그 후보, 발행 전 체크리스트(제휴 링크·광고 표시 문구·가격 기준일·이미지) | 3 |
| 🔔 알림 | 저장한 상품만 12시간마다 다시 확인 → 가격 하락·품절·재입고, 발행한 글 상품 품절 시 '글 수정 필요' | 2 |
| 캘린더 | 발행 예정 글(상태별 색), 협찬 마감, 세일·신상 일정(직접 입력), 기온 하강일, 할인 정보 글 제안 | 2 |
| 성과 | 블로그 RSS로 글 목록 자동, 검색 노출 순위(네이버 블로그 검색 상위 100개) 하루 한 번 자동, 조회수 직접 입력, 키워드별 성과 요약 | 3 |
| 설정 | 지역, 연령대, API 키, 관심 브랜드, 블로그 아이디, 지켜볼 키워드 | |

## 실행

1. [Node.js](https://nodejs.org) LTS(18 이상)를 설치합니다. 따로 설치할 패키지는 없습니다.
2. 이 폴더에서 실행합니다.
   - Windows (창 없이): `블로그 작업대.vbs` 더블클릭 → 업데이트 확인 후 브라우저가 열립니다. 웹 페이지를 모두 닫으면 15초 뒤 저절로 꺼집니다(설정의 [프로그램 끄기] 또는 `블로그 작업대 끄기.vbs`도 가능). 기록은 `data/app.log`.
   - Windows (검은 창으로 보면서): `실행하기.bat` 더블클릭
   - Mac: `실행하기.command` 더블클릭 (처음엔 우클릭 → 열기)
   - 또는 터미널에서 `npm start`
3. 브라우저에서 http://localhost:3000 을 엽니다.

API 키 없이도 **예시 데이터**로 모든 화면을 둘러볼 수 있습니다(화면에 노란 안내가 뜹니다).

## API 키

### 네이버 (검색어 트렌드 + 블로그 검색)
**2026년 7월 31일부터 네이버 개발자센터에서는 데이터랩·검색 API를 새로 신청할 수 없습니다.** 새 키는 네이버 클라우드 플랫폼의 **NAVER API HUB**에서 받습니다.

1. [네이버 클라우드 플랫폼](https://www.ncloud.com)에 가입·로그인합니다.
2. 콘솔에서 **NAVER API HUB** 이용을 신청하고 **Application을 등록**합니다.
3. 사용할 API로 **Search Trend(검색어 트렌드)** 와 **검색 - 블로그** 를 고릅니다.
4. 발급된 **Client ID / Client Secret** 을 프로그램 **설정 → 네이버 API** 에 넣고, 키 종류는 **NAVER API HUB 키**로 둡니다.

2026년 7월 이전에 개발자센터에서 받은 키가 있다면 키 종류를 **개발자센터 기존 키**로 바꾸면 됩니다(2027년 6월 30일까지 사용 가능하다고 안내되어 있습니다).

> 네이버 쇼핑 검색 API는 2026년 7월 31일 종료되어, '할인·신상'은 블로그 검색으로 브랜드 세일·신상 소식을 모으는 방식으로 바꿨습니다.

### 날씨
[공공데이터포털](https://www.data.go.kr)에서 '기상청_단기예보 조회서비스'를 활용 신청하고 서비스 키를 **설정 → 기상청 서비스 키** 에 넣습니다.

키는 이 컴퓨터의 `data/db.json`에만 저장됩니다. `.env` 파일(`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `NAVER_KEY_TYPE=hub|legacy`, `KMA_SERVICE_KEY`)로 넣어도 됩니다.

## 계산 방식

- **관심도 변화**: 데이터랩 일별 지수의 최근 7일 평균 ÷ 그 전 7일 평균. 오늘은 집계 중이라 어제까지 씁니다.
- **관심 수준**: 데이터랩 값은 요청마다 상대값이라, 모든 요청에 '코디'를 기준 키워드로 함께 넣어 '코디 = 100' 기준으로 맞춥니다. 1 미만은 추천에서 뺍니다.
- **블로그 글 수**: 네이버 블로그 검색 결과 총 건수(근사치).
- **기회 점수** = 관심도 변화 지수 ÷ log10(글 수 + 10). 참고용입니다.
- **오늘 주제 3개**: 기회 점수 × 시즌 적합도(오늘 또는 며칠 안 기온이 그 아이템을 입는 기온 범위면 가산).
- **브랜드 할인·신상**: 블로그 검색으로 '브랜드 + 세일', '브랜드 + 신상' 최근 글을 가져와, 제목·요약에 브랜드와 세일/할인(신상/신제품)이 함께 나오는 최근 2주 글만 보여줍니다. 지난번에 없던 글은 NEW로 표시합니다.
- **자동 작업**: 프로그램이 켜져 있는 동안 저장 상품 가격 확인(12시간), 브랜드 할인·신상(하루), 블로그 글 목록·검색 순위(하루)를 합니다. 꺼져 있던 동안 밀린 일은 켤 때 한 번 합니다.
- 외부 데이터는 하루 한 번 저장해 재사용하고, 가져오기에 실패하면 마지막 데이터와 갱신 시각을 보여줍니다.

## 지켜야 할 것 (기획서 '리스크와 주의사항')

- 상품 정보는 **내가 저장한 링크만, 저장할 때 한 번** 읽습니다. 쇼핑몰 전체 수집은 하지 않습니다.
- 썸네일은 앱 안 참고용입니다. 글에 쓸 이미지는 직접 촬영하거나 브랜드 허용 범위를 확인하세요.
- 협찬·제휴 상품이 담긴 보드에는 광고 표시 안내가 뜹니다. 최신 기준은 직접 확인하세요.
- 블로그 비밀번호는 받지 않습니다.

## 파일 구조

```
server.js          서버와 API
lib/catalog.js     기본 키워드·기온별 옷차림·지역·연령 코드·브랜드 사전
lib/naver.js       네이버 데이터랩/검색 API
lib/weather.js     기상청 단기예보, 격자 변환
lib/analysis.js    기회 점수, 급상승, 주제 3개 고르기, 아이템 집계
lib/product.js     상품 링크 자동 채움
lib/brandnews.js   관심 브랜드 세일·신상 소식 (블로그 검색)
lib/alerts.js      저장 상품 가격·품절 알림
lib/calendar.js    콘텐츠 캘린더
lib/helper.js      포스팅 도우미 (상품 표, 제목·태그, 체크리스트)
lib/performance.js 성과 기록 (RSS, 검색 순위)
lib/scheduler.js   자동 작업 주기
lib/service.js     화면용 데이터 모으기 + 하루 캐시
lib/store.js       data/db.json 저장
public/            화면(HTML/CSS, js/ 화면별 스크립트)
test/              npm test
```
